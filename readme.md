# 潮下之旅｜軟體規格書

版本 2.2 · 2026-11-18

## 開啟方式

雙擊 **index.html**，使用支援 WebGPU 且已啟用硬體加速的桌面瀏覽器。執行時只需要這一個 HTML，內含 CSS、JavaScript 與 WGSL。地形、生物、光效和環境音效均在本機生成。玩家也可授權選取本機 MP3。相簿的 JPEG 由當下畫面生成，可下載保存。

若瀏覽器在本機檔案網址下限制麥克風，可從專案目錄執行 `py -m http.server 8000 --bind 127.0.0.1`，再開啟 `http://localhost:8000/`。相簿與語言設定依瀏覽器的來源分開儲存。

## 海域與景點

| 順序 | 海域 | 場景特色 |
| --- | --- | --- |
| 1 | 海邊浮潛的淺灘 | 青綠沙岸、條紋魚群、寄居蟹、章魚、海星、海膽 |
| 2 | 廣西潿洲島的玻璃海 | 通透綠水、礁魚、團塊和枝狀珊瑚、花枝、海馬 |
| 3 | 馬爾地夫近海潛水 | 環礁藍水、礁蝠魟、綠蠵龜、小卷、水母、小丑魚、海葵 |
| 4 | 帛琉近海潛水 | 深藍海溝、礁鯊、珊瑚、海鰻、裸鰓海蛞蝓 |
| 5 | 淡水河道 | 河床礫石與水草、鯉魚、虹鱒、大口黑鱸、淡水長臂蝦、淡水溪蟹 |
| 6 | 北太平洋冷水海床 | 泥沙與礫石、冷水海藻、雪蟹 |

每個水域都有六個可重訪的全景視角。切換水域會回到首個景點。側欄的「生物觀察」選單列出當前水域的新增動物，共 17 種，選取後前往該生物附近。小丑魚沿著海葵所在位置巡游。地點、動物體型及配置均為風格化的遊戲設計。

## 渲染與效能

- 原生 WebGPU 管線每幀向 WGSL 傳入相機、時間、水域編號、解析度與品質。片段著色器使用逐像素射線步進繪製場景。
- 海床起伏由多尺度梯度 Perlin 噪聲形成。地形函數混入海溝深度場。拱、洞、沉船、鯨尾與生物以幾何距離函數組合。海藻位置、魚群和珊瑚以數學格點生成。
- 時間驅動藻帶、游魚、翼鰭與微粒。依水深與視距調整霧化，疊加動畫焦散、體積光近似積分和漂浮微粒。
- 魚群採用逐尾擺動的魚身、吻部、背鰭、胸鰭、臀鰭與分叉尾。魚眼、鰓線、鱗片反光與各海域花紋依魚身座標繪製。投放飼料或魚餌後，魚群會改變游動方向、聚攏並在餵食效果結束後散開。
- 物種模型使用 WGSL 幾何距離函數組合，各自使用獨立比例、材質和運動。水母傘部會脈動，章魚八腕、海葵觸手及甲殼類步足會擺動。淡水魚、小卷與花枝會向附近投食點靠近。
- 縮放範圍為原畫布線性解析度的 40–100%。有限制的 GPU 待處理幀數和移動平均幀間隔會觸發畫質調整。低品質會縮短射線距離、減少步數和體積光取樣。
- 流暢度目標為 60 FPS。實際幀率取決於 GPU、驅動、電源模式和顯示器更新率。

## MotionPad

在遊戲內選擇 Device A 或 Device B 並啟用麥克風。建議 Device A 使用 48 kHz，對應本遊戲的按格最高為 22 kHz。Device B 需 96 kHz USB 麥克風及相符的系統設定，最高為 34.5 kHz。音訊只在本機處理。

每 2,048 個樣本更新一次 4,096 點 Hann 窗 FFT，量化頻帶峰值與相鄰背景能量，再判定持續踩踏、釋放與衝突。輸入邊緣使用 MotionPad Creator Kit 0.2.0+t1 允許整合的參考邏輯。有 `window.MotionPad` 時使用主程式提供的踏墊事件。遊戲使用單組踏墊及玩家 0。
